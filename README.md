# Patient Management Application

A modern React-based patient management system built with Vite, Material-UI, and Axios. This application provides an intuitive interface for managing patient information and records.

## Features

- **Patient Table View**: Display and manage patient records in an organized data grid
- **Responsive Design**: Built with Material-UI for a professional, responsive interface
- **Client-Side Routing**: Navigate between different sections using React Router
- **API Integration**: Seamless backend communication using Axios
- **Modern Development Stack**: Powered by Vite for fast development and optimized builds

## Tech Stack

- **Frontend Framework**: React 19
- **Build Tool**: Vite 8
- **UI Component Library**: Material-UI (MUI) 9
- **HTTP Client**: Axios
- **Routing**: React Router DOM 7
- **Styling**: Emotion (CSS-in-JS)
- **Code Quality**: ESLint

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn

## Installation

1. Clone or navigate to the project directory:
```bash
cd patients_list
```

2. Install dependencies:
```bash
npm install
```

## Running the Application

### Development Server
Start the development server with hot module reloading:
```bash
npm run dev
```
The application will be available at `http://localhost:5173`

### Production Build
Build the application for production:
```bash
npm run build
```

### Preview Build
Preview the production build locally:
```bash
npm run preview
```

### Linting
Check code quality with ESLint:
```bash
npm lint
```
